# 全站内置材料目录

> 内置目录以 `catalog.js` 为唯一维护入口；既有 ID 和配方引用保持稳定。

## 信息模型（v2.7）

| 信息 | 职责 | 示例 |
| --- | --- | --- |
| 分类 | 浏览导航，不单独当作新原料使用 | 果汁、糖浆 |
| 原料 | 描述配方要求，不指定品牌 | 柠檬汁、伦敦干金酒 |
| 产品 | 名称 + 品牌 + 所属原料 | 孟买蓝宝石 / 孟买 / 伦敦干金酒 |
| 酒柜记录 | 所选原料或产品 + 个人备注名 + 笔记 | 家里这瓶、10 月开封 |
| 别名 | 搜索同一个定义的其他名称 | 英文名称、常见译名 |
| 匹配关系 | 原料的上下级及既有明确关系，自动计算 | 君度可满足橙味利口酒 |
| 配方替代项 | 仅在这份配方中允许的额外原料 | 作者明确指定的替代产品 |

- 产品归属于一种原料，不归属于其他品牌产品。品牌相同不代表两个产品可以互换。
- 品牌果汁也能归属于“柠檬汁”等具体通用原料；不再受旧数据中 `kind: product` 的历史命名影响。界面语义由导航分组与实际品牌信息确定，避免把无品牌的鲜果、果汁误称为产品。
- 通用原料不能反向满足指定品牌产品，鲜水果不自动等于果汁。上下级与明确替代项仍保持方向性。
- 酒柜的品牌来自产品定义，不再重复录入。备注名与笔记不参与匹配；用户更改名称不会暗中改变其对应原料。
- 产地与风格等补充分类定义在原料或产品上，使用同一目录选择，可包含自建类型。补充分类是真实匹配关系；一款牙买加黑朗姆可同时归入黑朗姆与牙买加朗姆。酒柜的开封、香气与口感写在笔记中，不参与类型判断。
- 旧名称识别在校验迁移时一次性解析为原料 ID，标记 `identityMode: explicit`。不明确的名称不猜测；其他旧匹配和标签保留。旧记录额外匹配可主动清理，普通编辑不会删除它们。迁移前的本机数据保留在 `backup-before-material-model`。
- 搜索名称 / 别名 / 品牌命中优先，相关分类命中单独展开；结果区分原料和品牌产品。导航分组保留内部引用，但不混入新原料选项。
- 新增表单统一填写名称、类型和可选品牌，不要求先选择角色；别名按需展开。类型支持名称、别名与带父级的明确选项。重复定义提供“使用已有条目”，已有类型或产品可创建多条独立酒柜记录；只阻止同一产品定义被重复创建。

### 同名原料与旧数据修复

- 库存和酒谱必须引用同一个原料 ID；两个名称相同的独立定义不会天然互相匹配。安装目录、导入、保存与同步流程统一修复已确认的重复定义。
- 仅当自建条目的名称命中内置名称或明确别名，且所属原料、匹配边界、特征相同，并且双方无品牌、没有图片冲突时才归并。多义名称不猜测，品牌和不同加工形态不互换。
- 保留原料别名和图片，并迁移正文、装饰、替代项、比例版本、产品父级、标签及库存引用。库存记录不合并，备注名、笔记与记录 ID 保留。旧备份再次导入不会复活重复定义。
- 青柠与鲜青柠、柠檬与鲜柠檬、西柚汁与葡萄柚汁采用统一定义。橙汁统一以“橙汁”展示，保留“鲜橙汁”等搜索别名；鲜榨建议由具体配方表达，果汁与果泥仍是不同原料。
- 升级前本机数据保存在 IndexedDB 的 `backup-before-material-dedup`。原料归并不引入任何草稿提示。
- 所有分类统一使用可展开的真实关系树，节点名称展开下级，旁边的加号选择当前类型。没有内置特征专属分组；自建条目与内置条目按同样规则出现。名称搜索显示完整路径；新建与编辑均可浏览分类目录，不要求记住类型名。

## 录入与取消

酒柜添加先选择，点击“添加 N 项”一次性提交。关闭、取消、Escape 不写入记录，也不恢复旧输入。新建原料如果尚未随酒柜或配方提交，取消父表单时一起丢弃。默认浏览按分类组织，拥有与点击历史不影响顺序；具体界面取舍见 [交互审查](ux-review.md)。


## 酒柜记录与产品定义

同一个产品定义可对应多条酒柜记录。添加选择器显示“已有 N 项”供参考，仍允许选择；资料库的“再添加”创建新的记录。每条记录有独立 ID、显示名称与笔记，删除其中一条不会删除其他记录或产品定义。记录改名不改变匹配身份。

新建“唐胡里奥银牌”的操作：添加原料 → 新建 → 填写名称 → 从所属类型目录选择龙舌兰 / 特基拉 / 银龙舌兰 → 品牌填写唐胡里奥 → 选中 → 添加。也可直接搜索所属类型。确认添加之前关闭父表单会取消未保存内容，不弹出草稿恢复提示。

目录修正还包括：香槟、普罗塞克、卡瓦属于起泡酒；君度属于 Triple Sec 与橙味利口酒；可可、薄荷、咖啡、草本等具体利口酒归入相应类型；安高天娜芳香苦精归入芳香苦精；咖啡归入饮品；可乐、姜汁饮料等归入气泡饮料。产品不能反向被任意同类替代。
