# 全站内置材料目录

> 内置目录以 `catalog.js` 为唯一维护入口。分类、原料定义、酒柜记录分别承担导航、配方匹配和实际拥有状态；显示名称与品牌不改变匹配关系。

## v2.3 录入规则

- 搜索优先匹配名称、别名及品牌；只有分类关系命中的材料收在“相关分类中的原料”。
- 白兰地 / 利口酒的重复根节点，以及液体材料、固体材料、果汁、糖浆等导航分组不作为新材料选项；仍保留内部 ID 与既有引用。新增具体材料时可以把果汁、糖浆等分组作为所属类别。
- 鲜水果与果汁、通用酒种与指定品牌保留独立记录。只有明确的匹配或替代关系可以用于配方，不能仅因名称相似就合并。
- 个人酒柜中的名称与品牌用于辨认；选定的对应原料与特征用于匹配。低频字段默认收起。
